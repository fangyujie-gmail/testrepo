# TestRepo

A clean startup repository for validating MCP tooling and quick project scaffolding.

## Included

- Minimal Node.js app
- Simple `npm` scripts for start/test
- `.gitignore` for common noise
- Lightweight project structure ready for extension

## Quick start

```bash
npm install
npm start
```

## Scripts

- `npm start` — runs the app
- `npm run dev` — runs in watch mode
- `npm test` — runs built-in Node tests

This repo is intentionally simple so it can be used as a baseline for testing automation, validation, and tool calls.
